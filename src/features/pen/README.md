# Pens

`Pen.tsx` owns one player's model and accepts `slot`, `model`, optional `color`, and the loaded `matadorTemplate`. Its registered handle lets the controller apply physics snapshots without React rendering every frame.

`ui/PenSelector.tsx` is the controlled picker reused by all mode screens; `ui/PenPreview.tsx` and `ui/PenPointer.tsx` supply menu visuals. `src/config/pens.ts` owns metadata, balance and custom palettes. `catalog.js` re-exports the resolved configuration for menus and physics; `types.ts` derives `PenKind` from the raw catalogue keys.

`ui/pen-selection.css` sizes cards against each selector's available width with container queries. Wide selectors use multiple columns with previews above the text; narrower selectors use readable full-width rows, and very narrow split panels stack the preview above the name. Custom-color controls wrap within the same container. Main-menu pointer graphics occupy a reserved slot in the active button rather than a measured floating position, and each SVG has its own gradient ID.

`models/pen-models.js` handles materials, texture caching, model selection, transforms and disposal. `standard-pen.js`, `matador-high-school.js`, and `matador-smoothy.js` contain the actual mesh construction. To add a pen, add its entry in `src/config/pens.ts`, style and builder. Test both model geometry and human-vs-AI selection. Repeated selections keep the same meshes; changed selections release the previous geometry.

Fall orientation comes from the physics recording: the holder rotates about the recorded desk-edge normal, retaining pen yaw and barrel roll. The model's convex cross-section is cached when built; its lowest rolled cap/clip point sets resting height. This keeps original proportions and prevents trim sinking into the desk. `tests/edge-fall.test.js` checks real mesh triangles against the desktop during recorded edge/corner falls, including sliding and spinning departures.

Matador High School uses the user-supplied `public/models/pens/matador-hi-school.glb`. `models/assets.js` owns its versioned URL, which the page preloads before the game bundle runs. Update its SHA-256 prefix when replacing the GLB; `tests/loading.test.js` checks the version. Versioned requests receive immutable browser caching. `models/load-pen-assets.js` caches its loading promise; `GameScene` waits for it before mounting the scene. `matador-high-school.js` clones resources per player, aligns the authored X axis with physics, fits its length and cross-section to the catalogue dimensions for board visibility, and recolours only the barrel materials. Keep the printing, nib and translucent cap materials intact. The template is never rendered, and each player's cloned resources can be disposed independently.

Mouse, touch and stylus safety tests cover every catalogue model under every camera preset on narrow/wide canvases and at zoom limits. Saved IDs and custom colours must be strings; coercible arrays are rejected during hydration. Run scene/engine/match-option/gesture tests after changing dimensions, and inspect printing/cap/readability in the browser. [Testing guide](../../../docs/testing.md).
